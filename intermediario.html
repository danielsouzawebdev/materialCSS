CSS Intermediário

Pré-requisito: CSS Básico. Aqui o foco muda de estilizar um elemento sozinho para organizar vários juntos.

1. Flexbox completo

Flexbox alinha itens em uma única direção — linha ou coluna — distribuindo o espaço entre eles.

.menu {
  display: flex;
  flex-direction: row;           /* row (padrão) ou column */
  justify-content: space-between; /* eixo principal */
  align-items: center;            /* eixo cruzado */
  flex-wrap: wrap;                /* quebra linha se não couber */
  gap: 1rem;
}

display: flex; justify-content: space-between;

Propriedades dos itens

.item-principal {
  flex-grow: 2;    /* cresce 2x mais que os irmãos quando sobra espaço */
  flex-shrink: 1;  /* pode encolher se faltar espaço */
  flex-basis: 200px; /* tamanho de partida, antes de crescer/encolher */
}

.item-ao-final {
  order: 99;        /* muda a ordem visual, sem mudar o HTML */
}

.item-sozinho {
  align-self: flex-end; /* sobrescreve o align-items só para este item */
}

flex: 1 é um atalho muito comum — equivale a flex-grow: 1; flex-shrink: 1; flex-basis: 0;, e faz o item crescer para ocupar todo espaço disponível, dividido igualmente com outros itens com flex: 1.

2. Posicionamento e z-index

.normal   { position: static; }    /* padrão, segue o fluxo da página */
.relativo { position: relative; top: 4px; left: 4px; }
.absoluto { position: absolute; top: 0; right: 0; }
.fixo     { position: fixed; bottom: 0; }
.grudento  { position: sticky; top: 0; }
ValorComportamento
staticpadrão — segue o fluxo normal da página, top/left não fazem nada
relativedesloca a partir de onde o elemento estaria normalmente, sem afetar os outros
absolutesai do fluxo; posiciona relativo ao ancestral posicionado mais próximo
fixedfixo na janela do navegador, mesmo rolando a página
stickynormal até atingir um limite de rolagem, depois gruda
A armadilha do absolute

position: absolute só funciona de forma previsível se algum elemento pai tiver position: relative — senão ele se posiciona relativo à página inteira (o <html>), o que raramente é a intenção.

z-index

.modal { position: fixed; z-index: 100; }
.overlay { position: fixed; z-index: 90; }

z-index só tem efeito em elementos posicionados (qualquer position diferente de static) — e decide qual fica "por cima" quando dois se sobrepõem. Maior valor, mais para frente.

3. Pseudo-classes e pseudo-elementos

a:hover { color: red; }
input:focus { border-color: blue; }
input:disabled { opacity: 0.5; }

li:first-child { font-weight: bold; }
li:last-child { border-bottom: none; }
li:nth-child(2n) { background: #f5f5f5; }   /* itens pares */
li:nth-child(odd) { background: #fff; }      /* itens ímpares */

p::first-letter { font-size: 2em; }
li::before { content: "→ "; }
input::placeholder { color: #999; }

Pseudo-classes (um dois-pontos, :hover) selecionam um elemento que já existe, num certo estado. Pseudo-elementos (dois dois-pontos, ::before) criam algo que não existe no HTML — útil para ícones decorativos ou numeração customizada, sem poluir o HTML com elementos vazios só para estilo.

4. Variáveis CSS

:root {
  --cor-principal: #1572B6;
  --cor-texto: #222;
  --espaco: 1rem;
  --raio: 8px;
}

.botao {
  background: var(--cor-principal);
  padding: var(--espaco);
  border-radius: var(--raio);
}

/* com valor de reserva, caso a variável não exista */
.card { padding: var(--espaco-card, 1rem); }

Diferente de uma variável do Sass (que vira um valor fixo depois de compilado), uma variável CSS continua viva no navegador — pode ser lida e alterada por JavaScript em tempo real, e seu valor pode mudar dependendo de onde ela é redefinida na árvore do documento.

Por que isso importa

Trocar a cor principal do site inteiro passa a ser mudar uma linha em :root, em vez de caçar a cor em dezenas de regras espalhadas pelo arquivo.

5. Transições

.card {
  transform: translateY(0);
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0,0,0,0.15);
}
ParteExemplo
propriedadetransform, opacity, background-color...
duração0.2s, 200ms
timing functionease, linear, ease-in-out

Anime transform e opacity sempre que possível — o navegador consegue acelerar essas duas por hardware. Animar width, top ou margin funciona, mas é mais pesado para o navegador recalcular.

6. calc() e clamp()

.sidebar {
  width: calc(100% - 240px);  /* mistura unidades diferentes numa só conta */
}

h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
  /* nunca menor que 1.5rem, nunca maior que 3rem,
     e cresce com a largura da tela (4vw) entre esses limites */
}

calc() faz contas misturando unidades que normalmente não dariam para combinar (porcentagem com pixels, por exemplo). clamp(mínimo, ideal, máximo) resolve um problema comum de tipografia responsiva — texto que escala suavemente com a tela, mas sem nunca ficar ilegível de tão pequeno, nem gigante demais.

7. Overflow e scroll

.caixa {
  height: 200px;
  overflow-y: auto;    /* barra de rolagem só se o conteúdo não couber */
}

.galeria {
  display: flex;
  overflow-x: scroll;   /* sempre com barra de rolagem horizontal */
  scroll-snap-type: x mandatory;
}
.galeria img { scroll-snap-align: start; }
ValorComportamento
visiblepadrão — conteúdo que não cabe vaza para fora da caixa
hiddencorta o que não cabe, sem barra de rolagem
scrollsempre mostra a barra de rolagem
automostra a barra só quando necessário

scroll-snap-type é o que faz carrosséis de imagem "encaixarem" ao parar de arrastar, sem precisar de nenhuma linha de JavaScript.

8. Formulários estilizados

input, textarea, select {
  font: inherit;        /* herda a fonte da página, em vez da fonte padrão do sistema */
  padding: 0.6em 0.8em;
  border: 1px solid #ccc;
  border-radius: 6px;
}

input:focus {
  outline: none;
  border-color: #1572B6;
  box-shadow: 0 0 0 3px rgba(21, 114, 182, 0.2);
}

input:invalid:not(:placeholder-shown) {
  border-color: #c0392b;
}

input:disabled {
  background: #f0f0f0;
  cursor: not-allowed;
}

Nunca remova o outline no :focus sem colocar algo visível no lugar (como o box-shadow acima) — sem indicação visual de foco, quem navega só pelo teclado perde completamente a noção de onde está na página.

Exercício

Construa um menu de navegação horizontal com Flexbox (justify-content: space-between), onde os links ganham sublinhado animado com transition no :hover, usando position: sticky para o menu grudar no topo ao rolar a página.

Projeto do nível: cards de produto responsivos

Monte uma seção com 4 a 6 "cards" de produto (imagem, título, preço, botão), usando:

  • Flexbox com flex-wrap: wrap para os cards quebrarem linha naturalmente
  • Variáveis CSS em :root para a cor principal e o espaçamento padrão
  • Uma transição suave de elevação (transform + box-shadow) no :hover de cada card
  • O botão de "Comprar" com estados :hover e :focus visualmente diferentes
  • Um cabeçalho fixo no topo com position: sticky
