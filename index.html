A primeira coisa a entender: o box model

Todo elemento HTML vira, na tela, uma caixa retangular — mesmo um link de texto simples. Essa caixa tem quatro camadas, de dentro para fora, e quase todo problema de "por que esse espaçamento está estranho" se resolve entendendo essas quatro camadas:

margin
border
padding
content

Isso volta em detalhe no primeiro módulo do nível Básico — por enquanto, só guarde a ordem: content → padding → border → margin, de dentro para fora.

Como usar este material

  • Tenha a página de portfólio do material de HTML pronta — é nela que os exercícios deste material vão ser aplicados.
  • Editor: Visual Studio Code com a extensão Live Server, para ver cada mudança de CSS instantaneamente.
  • Ferramentas do Desenvolvedor (F12) → aba Elements: clique em qualquer elemento da página e veja, do lado direito, o box model dele desenhado em tempo real.
