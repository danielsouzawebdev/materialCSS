CSS Básico

Oito módulos curtos. No fim, você estiliza a página de portfólio do material de HTML inteira.

1. Como aplicar CSS

Existem três formas de ligar CSS a um HTML — na prática, você vai usar quase sempre a terceira:

<!-- 1. Inline: direto no atributo style. Evite — mistura conteúdo e estilo -->
<p style="color: red;">Texto vermelho</p>

<!-- 2. Interno: dentro de <style> no <head>. Serve para testes rápidos -->
<head>
  <style>
    p { color: red; }
  </style>
</head>

<!-- 3. Externo: um arquivo .css separado. O jeito certo para projetos reais -->
<head>
  <link rel="stylesheet" href="estilo.css">
</head>

Um arquivo externo permite que uma folha de estilo controle várias páginas HTML ao mesmo tempo, e o navegador guarda esse arquivo em cache — carrega uma vez, reaproveita em todas as páginas do site.

2. Seletores

/* por tag */
p { color: #333; }

/* por classe — a mais usada no dia a dia */
.destaque { color: red; }

/* por id — só existe um elemento com esse id na página */
#topo { background: black; }

/* descendente — todo <a> dentro de <nav>, em qualquer profundidade */
nav a { text-decoration: none; }

/* filho direto — só <li> que é filho IMEDIATO de <ul> */
ul > li { margin-bottom: 4px; }

/* vários seletores com a mesma regra */
h1, h2, h3 { font-family: sans-serif; }
SeletorEspecificidade (prioridade)
tag (p, div)mais baixa
classe (.destaque)média
id (#topo)alta

Prefira classes no lugar de ids para estilizar. Ids são únicos por página, o que torna difícil reaproveitar o estilo em outro elemento — guarde ids para âncoras de link e para o JavaScript.

3. Box model

Como visto na página inicial, todo elemento é uma caixa com quatro camadas:

.caixa {
  width: 200px;
  padding: 16px;             /* espaço interno, entre o conteúdo e a borda */
  border: 2px solid #333;
  margin: 24px;               /* espaço externo, entre a caixa e os vizinhos */
  box-sizing: border-box;     /* ver abaixo */
}
CamadaO que é
contento conteúdo em si (texto, imagem)
paddingrespiro entre o conteúdo e a borda
bordera borda da caixa
marginespaço entre esta caixa e as vizinhas; pode ser negativo

box-sizing: a armadilha mais comum do CSS

/* padrão do navegador: content-box */
.caixa-a {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  /* largura REAL na tela: 200 + 20+20 + 2+2 = 244px */
}

/* com border-box, width já inclui padding e border */
.caixa-b {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  /* largura REAL na tela: exatamente 200px */
}
Prática quase universal

Por isso praticamente todo projeto começa com este reset:

* { box-sizing: border-box; }

Isso faz width significar "largura total", sem precisar calcular padding e borda na mão.

4. Cores e unidades

.texto {
  color: #1572B6;              /* hexadecimal */
  background: rgb(240 240 240); /* vermelho, verde, azul */
  border-color: hsl(205 76% 40%); /* matiz, saturação, luminosidade */
}
UnidadeRelativa aQuando usar
pxnada — valor fixobordas finas, detalhes que não devem escalar
%o elemento pailarguras fluidas
emo tamanho de fonte do próprio elementoespaçamentos que devem crescer junto com o texto
remo tamanho de fonte da raiz (html)tamanhos de fonte e espaçamento em geral — a mais usada

rem é previsível: 2rem é sempre o dobro do tamanho base da página, não importa onde o elemento esteja aninhado. em acumula — um em dentro de outro em multiplica, o que surpreende quem não está esperando.

  color: #222;
}

h1 {
  font-size: 2.5rem;
  font-weight: 700;
  text-align: center;

a {
  text-decoration: underline;
}

.citacao {
  font-style: italic;
  letter-spacing: 0.02em;

font-sizetamanho

6. Display

span { display: inline; }         /* ocupa só o espaço do conteúdo, lado a lado, ignora width/height */
div  { display: block; }           /* ocupa a linha inteira, aceita width/height */
.btn { display: inline-block; }    /* lado a lado, mas aceita width/height */
.oculto { display: none; }         /* some da página — não ocupa espaço nenhum */

Diferença visual

inline fica ao lado
block ocupa a linha inteira

display: none é diferente de deixar invisível mantendo o espaço — isso é visibility: hidden, que será visto no nível Intermediário junto de outras formas de esconder elementos.

7. Background e bordas

.card {
  background-color: #f5f5f5;
  background-image: url("textura.png");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;

  border: 1px solid #ddd;
  border-radius: 12px;         /* cantos arredondados */
  border-top: 4px solid #1572B6; /* borda só de um lado */
}

background-size: cover faz a imagem preencher todo o elemento sem distorcer, cortando o excesso — é o que quase todo banner de site usa. contain faz o oposto: encolhe a imagem até caber inteira, sem cortar nada.

8. Listas e estados de link

ul {
  list-style: none;    /* remove as bolinhas padrão */
  padding: 0;
}

a:link    { color: blue; }     /* nunca visitado */
a:visited { color: purple; }   /* já visitado */
a:hover   { color: red; }      /* mouse em cima */
a:active  { color: orange; }   /* no exato momento do clique */

A ordem importa: escreva sempre link, visited, hover, active nessa sequência (um truque de memorização comum é "LoVe HAte"). Fora de ordem, um estado posterior na folha de estilo pode silenciosamente sobrescrever um anterior.

Exercício

Remova as bolinhas de uma lista de navegação e transforme cada li em um item horizontal lado a lado usando display: inline-block — a base de um menu, antes de aprender Flexbox no próximo nível.

Projeto do nível: estilize o portfólio

Pegue a página de portfólio pessoal que você montou no material de HTML Básico (ou crie uma nova com a mesma estrutura) e aplique:

  • Um arquivo estilo.css externo, ligado via <link>
  • * { box-sizing: border-box; } logo no topo do arquivo
  • Uma paleta de no máximo três cores, usando hex ou hsl
  • Uma fonte diferente da padrão do navegador, com fallback
  • O header com background de cor sólida e os links do nav sem sublinhado, virando sublinhado só no :hover
  • As fotos ou avatar com border-radius para ficarem arredondadas
