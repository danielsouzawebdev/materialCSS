# CSS na Prática

Site estático (HTML + CSS puro, sem JavaScript) dedicado só a CSS, do zero ao avançado.

## Estrutura

```
.
├── index.html          # página inicial — box model e roteiro
├── basico.html          # nível 1 — 8 módulos + projeto
├── intermediario.html   # nível 2 — 8 módulos + projeto
├── avancado.html         # nível 3 — 8 módulos + projeto
├── assets/
│   └── css/
│       └── style.css
└── README.md
```

## Como publicar no GitHub Pages

1. Envie os arquivos para a raiz de um repositório GitHub (mantendo `assets/` no mesmo nível de `index.html`).
2. **Settings** → **Pages** → **Source**: `Deploy from a branch` → branch `main`, pasta `/ (root)`.
3. O link aparece em `https://SEU-USUARIO.github.io/SEU-REPOSITORIO/` em alguns minutos.
